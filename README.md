# ForceJoin — 强制入群

新成员入群后自动提醒，要求在限定时间内加入任意一个指定目标群；超时未加入则自动移出。

可选开启目标群自动清理：成员退出所有生效群后，自动从目标群移出。

## 功能

- **入群引导**：新成员入群后 @ 对方并发送引导消息
- **多目标群**：可配置多个目标群，加入任意一个即可；已在任意目标群的成员直接完成验证
- **加群确认**：通过目标群入群事件即时确认，并每 10 秒主动检查待处理成员；检测到加入任意目标群后自动解除禁言并在原群发送确认通知
- **超时移出**：超过时限且实时查询确认所有目标群均未加入时自动移出；查询异常时保留记录，等待下次检查
- **入群禁言**（可选）：新成员入群立即禁言，完成加群后自动解除
- **群级过滤**：群白名单/黑名单控制生效范围
- **用户豁免/拒绝**：白名单免规则，黑名单立即移出
- **目标群清理**（可选）：定时检查目标群成员，并在生效群退群时立即检查；仍在任意生效群的成员保留，已退出所有生效群的成员从目标群移出
- **手动清理**：群主或管理员可通过 `/forcejoin_cleanup` 立即检查所有目标群，并查看清理结果
- **持久化**：基于 AstrBot KV 存储，重启不丢失

## 工作流程

```
新成员入群事件
  ├─ 目标群未配置 → 跳过
  ├─ 来自任意目标群 → 待处理列表中？→ 解除禁言 + 原群通知 + 移除记录
  └─ 来自其他群 → 群过滤 → 用户过滤
      ├─ 已在任意目标群 → 发送完成通知
      └─ 尚未加入目标群 → 禁言(可选) → 引导消息 → 记录待处理

后台任务（每 10s）
  └─ 实时查询待处理成员的目标群状态
      ├─ 已在任意目标群 → 解除禁言 + 原群通知 + 移除记录
      ├─ 确认所有目标群均未加入且已超时 → 解除禁言 → 移出群聊
      └─ 查询异常 → 保留记录，等待下次检查

目标群自动清理（可选，默认每 10 分钟）
  └─ 汇总所有生效群成员 → 检查各目标群 → 对待移出成员实时核对所有生效群
      ├─ 仍在任意生效群或查询异常 → 保留目标群资格
      └─ 确认已退出所有生效群 → 移出目标群

生效群退群事件（主动退群或被踢）
  └─ 清除该群待处理记录 → 自动清理已开启？
      └─ 实时核对所有生效群（含事件所属群）
          ├─ 仍在任意生效群、已重新入群或查询异常 → 保留目标群资格
          └─ 确认已退出所有生效群 → 从所有目标群移出
```

## 配置项

| 键 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `target_group_ids` | list | `[]` | 目标群号列表，加入任意一个即可；非空时优先使用 |
| `target_group_id` | string | `""` | 兼容旧单目标群配置，目标群号列表为空时使用 |
| `target_cleanup_enabled` | bool | `false` | 开启目标群自动清理，同时启用定时检查和退群事件检查 |
| `target_cleanup_interval_minutes` | int | `10` | 定时清理间隔（分钟），最小为 `1` |
| `timeout_minutes` | int | `10` | 加群时限（分钟） |
| `welcome_text` | text | 见默认值 | 入群引导消息模板 |
| `completed_welcome_text` | text | 见默认值 | 完成加群后原群通知模板 |
| `kick_reason` | string | 未在规定时间内加入目标群 | 移出理由 |
| `mute_on_join` | bool | `false` | 入群时是否自动禁言 |
| `group_whitelist` | list | `[]` | 生效群白名单，留空全部生效 |
| `group_blacklist` | list | `[]` | 生效群黑名单 |
| `user_whitelist` | list | `[]` | 豁免用户（QQ号），免于入群验证和目标群清理；入群时拒绝用户优先 |
| `user_blacklist` | list | `[]` | 拒绝用户（QQ号） |

在 AstrBot 配置面板的「目标群号列表」中，每项填写一个群号，例如：

```json
{
  "target_group_ids": ["123456789", "987654321"]
}
```

成员加入 `123456789` 或 `987654321` 中的任意一个群即可完成验证。机器人需加入所有目标群，以查询成员信息并接收入群事件。所有目标群均作为验证目标，其他群的生效范围由群白名单和黑名单控制。

原有 `target_group_id` 配置可以继续使用；两项目标群配置均为空时插件不生效。使用自定义入群引导消息时，建议在文案中明确说明「加入任意一个目标群即可」。

### 目标群自动清理

在配置面板开启「自动清理目标群成员」，按需设置「目标群清理间隔（分钟）」。定时检查覆盖目标群现有成员，生效群的主动退群和被踢事件则立即检查离开的成员。

群主或管理员也可在生效群或目标群内发送 `/forcejoin_cleanup`，立即检查所有配置的目标群。手动清理可独立使用，自动清理开关仅控制定时检查和退群联动。命令会反馈成功移出、失败、跳过及状态不确定而暂缓的数量；同一成员从两个目标群移出计为两人次，暂缓人数按用户去重。已有清理任务运行时，会提示稍后再试。

- 生效群沿用 `group_whitelist` 和 `group_blacklist`：白名单非空时使用白名单中的群；白名单为空时使用机器人加入的所有群，再排除目标群和黑名单群。
- 成员仍在任意一个生效群就保留目标群资格；清理先请求刷新生效群成员列表，每次移出前再通过 `get_group_member_info`（`no_cache=true`）逐群核实，只有所有生效群都明确返回成员不存在时才移出。成员列表用于快速保留已有成员，退群事件所属群则在移出前重新核实。
- 退群事件只触发检查，核实时包含事件所属群，成员已重新加入任意生效群时保留目标群资格。查询异常或返回信息无效时，本轮暂缓清理该成员。
- 机器人自身和 `user_whitelist` 中的用户会被保留。目标群退群事件不会触发连锁清理。
- 没有可检查的生效群，或任一生效群成员列表查询失败时，跳过本次清理；个别目标群查询失败时，跳过该目标群并继续检查其他目标群。

例如，只以 `111111111` 和 `222222222` 两个群作为生效群，每 5 分钟清理一次目标群：

```json
{
  "target_group_ids": ["123456789", "987654321"],
  "group_whitelist": ["111111111", "222222222"],
  "target_cleanup_enabled": true,
  "target_cleanup_interval_minutes": 5
}
```

### 消息占位符

| 占位符 | 说明 |
|---|---|
| `{timeout}` | 超时分钟数 |
| `{target_group}` | 入群引导中为所有候选目标群号（以顿号分隔）；完成通知中为实际加入或检测到已加入的目标群号 |
| `{user_id}` | 用户 QQ 号 |
| `{group_id}` | 当前群号 |

## 管理指令

| 指令 | 权限 | 说明 |
|---|---|---|
| `/forcejoin_cleanup` | 生效群或目标群的群主/管理员 | 手动检查所有目标群并移出已不在任何生效群的成员，反馈清理结果 |
| `/forcejoin_status` | 群主/管理员 | 查看本群待处理成员及剩余时间 |
| `/forcejoin_remove <QQ号>` | 群主/管理员 | 手动移除待处理记录 |

## 支持平台

- aiocqhttp（OneBot v11）

## 依赖

- AstrBot >= 4.9.2
- 机器人需加入所有生效群和目标群，并在生效群拥有群管理权限（移出成员、禁言）
- 开启目标群自动清理时，机器人还需在目标群拥有移出成员的权限

## 安装

将插件目录放入 AstrBot 的 `plugins/` 目录，重启即可。

```bash
cd AstrBot/plugins
git clone https://github.com/youshen2/astrbot_plugin_forcejoin.git
```
